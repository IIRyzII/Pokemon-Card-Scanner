Current investigation

My final-year report investigates timing attacks on neuromorphic vision pipelines, which are built on spiking neural networks. These networks process information as events over time, so the time a pipeline takes to respond could reveal something about what it has seen. I am assessing what this kind of attack would mean for an automotive supplier, as a risk assessment.
